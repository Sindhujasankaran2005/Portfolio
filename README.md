# Sindhuja S. — Data Analyst Portfolio

A responsive pastel-purple portfolio for showcasing data analytics skills, projects, education, training, and contact details. Built with HTML, CSS, and vanilla JavaScript.


## Run locally
1. Extract the ZIP folder.
2. Open `index.html` directly in your browser, or use Visual Studio Code with Live Server.


## Customize before publishing
- Update the LinkedIn link in `index.html` to your exact profile URL.
- Update each project GitHub link to its individual repository (currently links point to your profile).
- Confirm email address and course/certificate status.
- Add a real profile photo if desired; the current hero uses an abstract initials graphic instead.
- Add a Resume PDF and link the button if you want a download option.


## Included
- `index.html` — portfolio content and layout
- `style.css` — responsive purple/white design
- `script.js` — mobile navigation and current-year footer
- `.gitignore` — Git ignore defaults
